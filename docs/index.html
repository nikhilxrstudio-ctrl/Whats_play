Automated Dark-Themed Email Templates for Blends

Automatic delivery of responsive, modern dark-themed HTML emails via Brevo SMTP relay. Creators receive a dedicated confirmation email with their unique 6-digit Join Code and management link upon creating a Blend, and can directly send tailored invitation cards with custom join codes to friends via email.

✨

Real-Time Shared Blend Music with Unique Join Codes

Connect with friends and blend music in real-time powered by Cloud Firestore. Each Blend features a unique 6-character uppercase code. User A can share their code with User B to join. Any song added by User A or User B immediately syncs in real-time across both devices with user attribution ("Added by [Name]"). Also integrates device telemetry and user activity logging into Firestore for future dashboards.

⚡

Smooth & Direct TabBar Transitions

Upgraded bottom navigation with native Flutter TabController and TabBarView across 3 Spotify-inspired tabs (Home, Search, Your Library). Navigating between tabs transitions directly with zero intermediary page flashing.

🎤

Real-Time Synchronized Lyrics

Added interactive Lyrics support directly in the Player screen powered by JioSaavn and LRCLIB fallback engines, featuring dynamic Ambient Glassmorphism styling.

🚀

Zero-Lag 60/120 FPS Performance & Scroll Optimization

Completely eliminated UI micro-stutters by scoping GetX reactive observers (Obx) to discrete playback widgets, ensuring seamless 120 FPS scrolling across infinite track shelves.

🎧

Artwork Carousel Sync & Auto-Play

Selecting any song from similar categories or artist shelves immediately launches audio streaming and animates the high-resolution artwork carousel in real-time lockstep.

Crisp Android Media Notification & Lock Screen

Resolved system media player icon scaling with a high-resolution transparent vector icon and updated ProGuard keep-rules for bulletproof background audio resilience.

Key Capabilities

🎧

Dual-Engine Music Streaming

Integrates legitimate JioSaavn regional streaming endpoints and decentralized Audius protocol REST streams for full-length, high-bitrate playback.

🇮🇳

Regional Indian Discovery

Rich catalogs dedicated to Bollywood chartbusters, Punjabi hits, and Gujarati melodies, plus artist spotlights (Diljit, Honey Singh, Arijit, Sidhu, Badshah).

📊

Ranked Top 50 Charts

Real-time India Superhits Top 50 ranked list featuring #1 through #50 ranking badges, Taaza Tunes (New Releases), and curated Romantic and Party shelves.

📱

Lock Screen & Background Audio

Uninterrupted playback powered by audio_service and just_audio with native OS notification drawer and lock screen controls.

💾

Offline SQLite Library

Client-side SQLite database for Liked Songs, Custom Playlists, 10-second Listening History, and sandboxed offline MP3 downloads without an internet connection.

🎨

Ambient Gradient Visuals

Spotify-style dark mode interface featuring dynamic background color extraction from album artwork and live animated sound wave equalizers.

Quick Installation

# Clone the repository
git clone https://github.com/nikhilxrstudio-ctrl/Whats_play.git
cd Whats_play

# Fetch dependencies
flutter pub get

# Run static analysis & test suite
flutter analyze
flutter test test/controllers/ test/widget_test.dart

# Launch WhatsPlay
flutter run
